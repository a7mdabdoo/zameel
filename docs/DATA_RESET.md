# دليل مسح البيانات قبل إطلاق النسخة التجريبية (Pilot Data Reset)

نظراً لأن النسخة التجريبية (Pilot) لم تبدأ بعد، ولا توجد بيانات إنتاجية حقيقية، يتم مسح المجموعات التالية من Firestore:

## 1. مجموعة الرسائل العامة (Top-level `/messages`)
- **السبب:** تم نقل المحادثات كلياً لتصبح مجموعة فرعية داخل كل جلسة (`/sessions/{sessionId}/messages/{messageId}`)، وحذف قواعد الوصول للمجموعة العامة لمنع تسريب الرسائل.
- **الإجراء:** مسح أي مستندات موجودة في Root Collection المسماة `messages`.

## 2. مجموعة أسماء المستخدمين (`/usernames`)
- **السبب:** ميزة حجز أسماء المستخدمين لم تعد مستخدمة في التطبيق، وتمت إزالة قواعدها بالكامل لمنع أي قراءة عامة للبيانات.
- **الإجراء:** مسح أي مستندات موجودة في Root Collection المسماة `usernames`.

## 3. حماية خصوصية الطلاب في مجموعة المستخدمين (`/users`)
- **السبب:** لمنع سحب بيانات الطلاب أو استكشاف هوياتهم بالجملة، تم إيقاف عملية الـ `list` (`allow list: if false`) مع الإبقاء فقط على جلب مستند واحد مسجل (`allow get: if isAuthenticated()`).
- **إزالة البريد الإلكتروني:** تم التوقف عن تخزين حقل `email` في مستندات Firestore، لأن البريد محفوظ ومحمٍ بشكل مستقل داخل Firebase Authentication ويصل إليه صاحبه فقط عبر `currentUser.email`.
- **الإجراء:** عند تهيئة البيانات التجريبية، يتم حذف حقل `email` من مستندات `users`.
