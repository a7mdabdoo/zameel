# الهوية البصرية لمنصة «زميل» (Zameel Brand Identity)

## 1. فلسفة الشعار الهندسي (The Brand Mark)
تم استبدال الأيقونة التقليدية القديمة بشعار هندسي عصري يحمل رمزية عميقة:
- **المونوجرام «ز»**: تشكيل هندسي مستوحى من الحرف العربي الأول لمنصة «زميل».
- **القوسان المتشابكان (Interlocking Arcs)**: يرمزان إلى طرفي عملية التعلّم التشاركي (الشارح والمتعلّم)، حيث يلتقي القوسان في مركز هندسي متزن يعبر عن التكافؤ، وتبادل الساعات والخبرات.
- **النقطة الهندسية (Knowledge Nuqta)**: دائرة مصمتة أعلى القوسين تمثل جوهر المعرفة المتبادلة.
- **الخصائص الفنية**: تصميم مسطح (Flat)، أحادي اللون (Monochrome-capable)، بدون تدرجات لونية، صالح للاستخدام بمقاسات تبدأ من 16px وحتى اللوحات الإعلانية.

## 2. ملفات ومكونات الهوية (Assets & Implementations)

### أ. الودجت البرمجي (Flutter CustomPainter)
- **المسار**: `lib/core/widgets/zameel_logo.dart`
- **الاستخدام**:
```dart
ZameelLogo(
  size: 56,
  color: context.tokens.brand,
)
```

### ب. الرسم المتجهي المتوافق مع الويب والتصميم (Vector SVG)
- **المسار**: `assets/brand/logo_mark.svg`
- **المواصفات**: `viewBox="0 0 512 512"`, مسار هندسي دقيق مع أطراف دائرية (`stroke-linecap="round"`).

### ج. أصول الأيقونات عالية الدقة (1024x1024 PNGs)
تم توليدها برمجياً بدقة متناهية وأبعاد متوافقة مع إرشادات Material Design للأيقونات المتكيفة (Adaptive Icons):
1. `assets/brand/app_icon.png`: الأيقونة الكاملة بخلفية العلامة المعتمدة (`#1F6F6B`) والشعار الأبيض.
2. `assets/brand/icon_foreground.png`: طبقة الشعار الشفافة مع مراعاة منطقة الأمان (Safe Zone 66%).
3. `assets/brand/icon_background.png`: طبقة الخلفية اللونية المصمتة.
4. `assets/brand/icon_monochrome.png`: الطبقة الأحادية لنظام الأيقونات المتكيفة في Android 13+.

## 3. إعداد الأيقونة وشاشة البداية (Launcher Icons & Native Splash)

تم تضمين الحزم الخاصة بالأدوات في `dev_dependencies` بملف `pubspec.yaml`:
```yaml
dev_dependencies:
  flutter_launcher_icons: ^0.14.3
  flutter_native_splash: ^2.4.4
```

### أوامر التوليد (Generation Commands):
لتطبيق الأيقونات المتكيفة لجميع المقاسات في مجلدات Android `res/mipmap-*` و iOS `Assets.xcassets`:
```bash
dart run flutter_launcher_icons
```

لتوليد شاشات البداية الأصلية للنظام في الوضعين النهاري والليلي (بما في ذلك شاشات Android 12+ Splash):
```bash
dart run flutter_native_splash:create
```
